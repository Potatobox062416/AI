# 进京赶考

北京团队旅行规划单页站点，包含景点索引、四图详情、多人年龄解析、详细往返班次、票单时间绑定、分钟级到离京时间、自动行程天数、3—5套行程、自编排程与冲突建议、升旗与开闭馆审查、午晚餐排程、美食资料、天气提醒、费用区间和门票预约清单。

## 本地运行

在本目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173/`。

## 数据说明

- 当前景点库含27处景点及108张配图；票价、预约规则与开放口径整理基准日：2026-09-03。
- 距出发16天以内时，页面通过 Open-Meteo 读取北京逐日预报；更远日期明确显示季节参考。
- 行程天数按到京日与离京日的自然日首尾计入；住宿晚数单独计算。
- 高铁、飞机和自驾的首尾接驳采用分段缓冲估算，并在计划中明确标注；往返方案会给出查询入口、预售提醒和可行性判断，但不代表实际车次、航班、余票或实时路况。
- 高铁和飞机模式支持录入多条去返程候选，记录班次、站点或机场、出发与到达时间、二等座或经济舱票价、余票状态；采用候选后，实际到离京时间和行程接驳会自动重算。
- GitHub Pages无法可靠跨站读取12306或航司的动态库存；页面不会伪造“实时余票”，班次数据由使用者根据官方查询结果录入，并显示为查询快照。
- 自编行程可从任一生成方案载入，逐日增删景点或餐食、修改开始时间和时长，并检查首尾接驳、开闭馆、周一闭馆、营业时间、重叠与通勤间隔。
- 2026年国庆升旗优先使用天安门地区管委会官方时刻表，其他日期由本地 SunCalc 推算日出并要求临行复核。
- 当前启用美食库含33家餐馆及66张配图，可按价位与三位视频作者筛选；餐馆事实、参考人均和视频资料核验于2026-09-03，静态站点不会在每次生成时实时抓取平台。
- 尹三豆汁仅按早餐店处理，不进入午餐候选；每套自动方案使用独立餐馆去重集合，同一餐馆不会重复推荐。
- 城际交通按出发地、返回地与北京的直线距离建立费用区间，不是铁路或航司实时报价。
- 酒店按每间2人估算，环球影城采用国庆动态票参考值；索道、游船、优速通和购物不计入基础预算。
- 景点图片来源记录在 `assets/attractions/*-image-credits.json`；餐馆配图来源记录在 `assets/restaurants/restaurant-image-credits.json` 与 `assets/restaurants/restaurant-image-replacements.json`。
- 当前图片集用于本地原型与学习展示；如需公开部署或商业使用，应逐张核对原页面授权并替换未明确开放许可的图片。
